# 蜂の巣撤去の費用相場

## 全体の相場

蜂の巣1個あたりの撤去費用は、**10,000円〜50,000円前後**が一般的な相場です。  
蜂の種類・巣の大きさ・設置場所・時期によって金額が大きく変わります。

---

## 蜂の種類別の相場

| 蜂の種類 | 費用相場 |
|----------|----------|
| スズメバチ | 20,000円〜60,000円（平均約46,000円） |
| アシナガバチ | 10,000円〜30,000円 |
| ミツバチ | 10,000円〜40,000円（巣の規模による） |

### スズメバチ
- 最も費用が高い。攻撃性が高く作業リスクが大きいため。
- 最多価格帯は **30,000円〜40,000円**。
- オオスズメバチは最低でも **20,000円〜** が相場。

### アシナガバチ
- スズメバチより攻撃性が低く、比較的安価。
- 相場は **10,000円〜20,000円** が中心。

### ミツバチ
- 基本的におとなしく、被害リスクは低め。
- ただし巣が大きい場合や壁内などへの営巣は高額になることがある。

---

## 費用に影響する主な要因

1. **巣の大きさ** ─ 大きいほど作業時間・薬剤量が増加
2. **設置場所** ─ 天井裏・壁内・高所は追加料金が発生しやすい
3. **蜂の種類** ─ 危険度が高いほど割増
4. **時期** ─ 夏〜秋（活動期）は費用が上がる傾向

---

## 費用を抑えるポイント

- **自治体の補助金・助成金を確認する**  
  一部の市区町村では撤去費用を全額または一部負担してくれる制度がある。
- **早期発見・早期対処**  
  巣が小さい段階（直径10cm以下）なら費用が安く済みやすい。
- **複数業者に見積もりを取る**  
  相見積もりで適正価格を把握することが重要。
