# Amazon定期おトク便 全解約ループ

Amazonの定期おトク便ページに「⚡ 定期便を全部解約」ボタンを追加するユーザースクリプトです。
ボタンを1回押すと、登録商品がなくなるまで以下を自動でループします。

1. 定期おトク便の管理画面(一覧)で商品ページを開く
2. 商品の詳細設定を開く
3. 「定期おトク便を停止する」を押す
4. 理由を選択して「登録をキャンセル」を押す
5. 一覧に戻って次の商品へ → 登録商品がゼロになったら終了

自分のブラウザ(ログイン済み)の中だけで動くため、Amazonのパスワードをどこかに保存する必要はありません。

## インストール

### PC (Chrome / Edge / Firefox)

1. 拡張機能ストアから [Tampermonkey](https://www.tampermonkey.net/) をインストール
2. Tampermonkeyのダッシュボード → 「新規スクリプト」
3. `amazon-teiki-cancel.user.js` の中身を貼り付けて保存

### iPhone (Safari)

1. App Storeで「**Userscripts**」(無料)をインストール
2. 設定 → Safari → 機能拡張 → Userscripts を有効化し、`amazon.co.jp` へのアクセスを許可
3. Userscriptsのフォルダに `amazon-teiki-cancel.user.js` を保存

### Android

1. **Firefox** をインストールし、アドオンから **Tampermonkey** を追加
2. あとはPCと同じ手順

## 使い方

1. Amazonにログインした状態で「アカウントサービス → 定期おトク便の情報を管理」を開く
2. 右下に出る「⚡ 定期便を全部解約」ボタンを押す
3. 確認ダイアログでOKを押すと、あとは全自動です
   (画面下に「[n件目] ○○をクリック中…」と進捗が表示され、
   全部解約し終わると「✅ 完了! n件すべて解約しました」と出ます)
4. 途中で止めたいときは、もう一度ボタンを押すと停止します

## 安全装置

- 20秒間なにも進展がない場合は自動で中断します(UI変更などで迷子になったとき用)
- 1回の実行で解約するのは最大100件までです
- 実行中にボタンを再度押すといつでも止められます

## 注意事項

- AmazonがページのUI・文言を変更すると動かなくなることがあります。その場合は
  スクリプト冒頭の `CONFIG` にある文言候補リストを、実際の画面のボタン文言に合わせて
  追記すれば直せます。
- 「まもなくお届け」メールが来た後(発送準備中)は解約が間に合わないことがあります。
- おまとめ割引(同月3件以上で10%オフ)を使っている場合、解約で件数が減ると
  残りの商品の割引率が下がることがあります。
- 本スクリプトは自分自身のアカウント操作を省力化するものです。利用は自己責任でお願いします。
