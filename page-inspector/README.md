# ページ診断ツール (Page Inspector)

どのサイトでも使える汎用の診断ユーザースクリプト。
自動化スクリプトを作るときの「ページ構造の下調べ」用。

## 機能

- 全サイトの右下に小さな🔍ボタンが常駐(半透明・36px)
- 🔍を押すと、そのページの以下をまとめて表示・コピーできる
  - URL / タイトル / iframe数
  - クリック可能要素の一覧 (タグ | 文言 | リンク先)
  - 入力欄の一覧 (type / name / id / placeholder)
- 「🎯 要素を調べる」: ページ上の調べたい要素をクリックすると、
  その要素の祖先チェーン(タグ・class・role・cursor)とHTMLを表示。
  クリックしてもリンク先への遷移は起きない。Escで中止。
- Shadow DOMの中まで探索する

## インストール

Tampermonkey(またはUserscripts)に `page-inspector.user.js` を
新規スクリプトとして貼り付けて保存するだけ。

普段邪魔なときは、Tampermonkeyのアイコンメニューからこのスクリプトの
トグルをOFFにすれば消える。

## 用途

「このサイトのこの操作を自動化したい」となったら:

1. 対象ページで🔍を押して全体レポートをコピー
2. 操作したいボタンがあれば「🎯 要素を調べる」でその要素のHTMLをコピー
3. その2つを開発者(Claude)に渡すと、実際のページ構造に合った
   自動化スクリプトを一発で書ける
